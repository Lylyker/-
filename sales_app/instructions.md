# Инструкция по запуску

1. Сборка:            make          (используется gcc с флагом -pthread)
2. Запуск:            ./sales_app   (или make run)
3. В консоли приложения:
     50000             — установить новый VIP-порог (аналитики пересчитаются сразу);
     threshold         — показать текущий порог;
     help              — справка;
     exit              — корректное завершение всех 5 потоков.
4. Результаты:
     sales.txt         — журнал продаж (генерируется потоком симуляции);
     products.txt,
     customers.txt     — тестовые справочники (создаются автоматически при первом запуске);
     app.log           — лог всех событий с временными метками.
5. Очистка:           make clean
